# Mundiz-Final-Frontend
React Frontend for School Management System

## Setup Instructions

```bash
clone my repository
cd Mundiz-Final-Frontend
npm install
cp .env.example .env
npm run dev
```
## Weather API Key
1. Go to https://openweathermap.org/api
2. Sign up for free
3. Copy your API key
4. Paste it in .env as VITE_WEATHER_API_KEY
